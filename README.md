# Rock Paper Scissors

A browser-based Rock, Paper, Scissors game where you play against the computer. Built with HTML, CSS and JavaScript.

## Live Demo
https://anushka-786.github.io/Rock-Paper-Scissors/

## Features
- Choose rock, paper or scissors by clicking
- The computer picks a random move each round
- Shows the winner of every round
- Keeps track of your score and the computer's score

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Play
1. Click rock, paper or scissors.
2. The computer makes its choice.
3. See who wins the round and watch the scores update.

## How to Run Locally
1. Download or clone this repository.
2. Open `index.html` in your browser.
